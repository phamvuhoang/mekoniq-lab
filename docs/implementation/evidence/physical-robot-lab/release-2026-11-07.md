## Rulings và phần còn mở

- Ruling: guide dùng tiếng Việt như tài liệu tham chiếu; UI ứng dụng VI/JA/EN giữ nguyên. Dịch guide là công việc bổ sung nếu cần.
- Ruling: acceptance khóa Source runtime commit và pin chính xác. Guide-only commit về sau không được coi là runtime export mới. Muốn chạy lại acceptance lịch sử phải dùng Source revision đã ghi; thay code phải export/pin/record/accept lại.

G0 còn blocked vì V14/V19 và project chung Designer/Twin chưa hoàn tất. G1/G2 chưa có Linux/ROS/Gazebo, MoveIt/contact/process native và campaign qualification. G3 cần dữ liệu đo thật; hardware và clean-machine/offline-native distribution chưa được nghiệm thu. Host preflight ghi 48,11 GiB trống so với VM budget 120 GiB cộng reserve 20 GiB; không provision VM.

UI còn thiếu entity-binding editor, provenance/model và link/joint/port inspector, exploded engineering view, project chung và stability. Assembly owner hiện chỉ đọc, add tự dùng entity runtime đầu tiên. Catalog cần rating có nguồn và vendor qualification. Các giới hạn này cũng hiện trong guide và compatibility; không thay bằng số preset hoặc bằng chứng mock.
