## Model scope and recovery

- Source domain/journal owns orders, inventory, custody and effects. Capacity, milk and measurement rules use explicit illustrative policies; they are not venue food-safety certification.
- Arm collision uses conservative capsule sweeps and explicit illustrative map/height profiles. Dynamic and parked AMRs participate; missing geometry/pose blocks clearance. Bounded traces retain the first failure and disclose truncation. No dynamics, torque, physical grip, fluid model, physical stop or sensing claim.
- Reclaim requires ownership proof and returns view/reconcile access with exact locked inputs. Unknown effects are never resent. Reset creates a new immutable run and retains old evidence. Replay projects recorded state at its cursor, including collision/stop events.
- The combined two-AMR food/coffee campaign ends after customer handoffs. Parking is covered separately by FD01, FD07 and FD02-cups.
- Duration comparisons retain their declared thresholds: same-input sim-time delta 0 ms; BV01 headless wall budget 30 s; FD01 10 s. Missing/censored values remain unavailable. See the acceptance JSON timing records.

## Historical backup failure

The old corruption test could overwrite a byte with its existing value. It now flips a bit and asserts that the dump changed; the verifier regression covers all 256 original byte values. The full recorded source integration suite is green. This removes the deterministic no-op weakness without asserting that it fully explains the earlier 2/4 failure rate.
