# Visual asset provenance

The robot model, restaurant SVG, brand mark recreation, and interface SVG paths are original procedural assets authored for MEKONIQ Robot Lab. No vendor model, CAD, image, or third-party icon library is included. The three-bar mark and exact color/font tokens preserve the repository's existing MEKONIQ presentation. Fonts use the system stack with no CDN dependency.

Three.js is pinned separately in package.json and retains its MIT license in node_modules/three/LICENSE. The procedural robot is illustrative, dimensionally approximate, and is not a certified mechanical design or supplier representation.
